# Proyecto Chinampa X

## Objetivos

- Ya no matar plantas

## Requerimentos
- python 3
- Arduino IDE
- ESP32 DOIT Devkit V1
- ESP32-S3 con Cámara AI DFR1154
- Humidificador 24V
- Ventiladores 12V
- Fuente Conmutada 12v 40A
- Celdas Peltier 134w
- Cable Calefactable
- MOSFETS IRLZ44N

## Descripción

- Chinampa X es un sistema que busca crear un micro-clima automatizado el cual le brinde a las plantas condiciones ideales para crecer.
